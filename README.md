# DSA_Java

A collection of Data Structures and Algorithms problems solved in Java.

## Topics

- Arrays
- Strings
- Searching
- Sorting
- Linked Lists
- Stacks
- Queues
- Hashing
- Trees
- Graphs
- Dynamic Programming

## Approach

Each problem focuses on:

- Understanding the problem
- Developing the algorithm
- Implementing the solution in Java
- Optimizing the solution
- Analyzing time and space complexity

This repository is maintained as part of my DSA and interview preparation.
